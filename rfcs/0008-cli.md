# RFC 0008: CLI verbs

- Feature Name: cli
- Type: Standards Track
- Status: Stable
- Created: 2026-09-09
- Author: Andrei Makarov
- Stakeholders: project maintainers
- Relates: RFC 0004, RFC 0005

## Summary

Specify the `partition_gardener` executable: `plan`, `audit`, and `apply`, registry context, and the `--confirm` gate on writes.

## Motivation

Operators run maintenance from a shell without a job. A missing confirm flag or a silent registry load would mutate the wrong database.

## Guide-level explanation

From a Rails app: `bundle exec partition_gardener --rails plan events --pretty`. Standalone: set `DATABASE_URL` and `partition_gardener --registry config/partition_garden.json audit --all`. Writes: `partition_gardener --rails apply --confirm events`. Without `--confirm`, apply prints help and exits.

## Reference-level explanation

### Verbs

`plan` and `audit` are read-only. They print JSON from RFC 0005. `apply` calls `PartitionGardener.run!` and prints `RunSummary` JSON. Unknown verbs and `help` print usage.

### Context

At least one of `--registry PATH`, `--rails`, or a pre-registered Ruby registry is required. `--registry` loads JSON (RFC 0004) and resets the registry. `--rails` requires `config/application.rb` walking up from the working directory, then loads `config/environment.rb`. `--registry` without `--rails` uses `DATABASE_URL` through `PgConnection`.

### Table selection

`--table NAME` or a positional name after the verb selects one parent. `--all` plans or audits every registered config. For `apply`, `--all` or an omitted table name runs the full gardener-owned registry. `plan` and `audit` without a table and without `--all` MUST fail with a table-required message.

### Confirm

`apply` MUST abort unless `--confirm` is set. `--pretty` pretty-prints JSON for every verb.

### Fail modes

No registry: abort with `no tables registered; pass --registry PATH or --rails`. Unknown table: abort with `no config for table`. Apply without `--confirm`: abort with `apply requires --confirm (mutates the database)`.

## Implementation notes

`lib/partition_gardener/cli.rb`.

## Registrar

Verbs `plan`, `audit`, `apply`. Flags `--rails`, `--registry`, `--table`, `--all`, `--pretty`, `--confirm`.

## Drawbacks

`--all` on apply still needs `--confirm`, which surprises copy-paste from plan examples. Envelope JSON for `--all` is not the single-table plan schema (RFC 0005).

## Rationale and alternatives

A confirm flag keeps apply from running on a mistyped table. Rejected: a separate `dry-run` verb; `plan` is the dry run.

## Prior art

pgslice CLI with an explicit `swap`. Many ops CLIs require `--yes` or `--confirm` for mutate.

## Unresolved questions

Whether apply without a table name should require `--all` instead of implying the full registry.

## Future possibilities

A `version` verb. Exit codes other than abort-on-message.
